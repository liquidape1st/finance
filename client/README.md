# Pulse - Deploy This Interface

Dự án React + TypeScript + Vite được tạo từ thiết kế Figma.

## Cài đặt

```bash
npm install
```

## Chạy dự án

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Cấu trúc dự án

```
pulse/
├── src/
│   ├── App.tsx          # Component chính
│   ├── App.css          # Styles cho App
│   ├── main.tsx         # Entry point
│   └── index.css        # Global styles
├── index.html           # HTML template
├── package.json         # Dependencies
├── tsconfig.json        # TypeScript config
└── vite.config.ts       # Vite config
```

## Lưu ý

Thiết kế từ Figma sẽ được triển khai vào các components trong thư mục `src/`.
